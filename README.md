#### **Word and Character Counter**



###### **Description**

This is a simple Python program that accepts a paragraph from the user and counts the total number of characters, words, sentences, and spaces.



###### **Technologies Used**

\- Language: Python

\- Tool: Python IDLE 



###### **Features**

\- Counts total characters, including spaces and punctuation.

\- Counts words using the 'split()' method.

\- Counts sentences using punctuation marks like '.', '!', and '?'.

\- Counts the total number of spaces.

\- Handles empty input.



###### **How to Run**

1\. Install Python on your computer.

2\. Copy the program into a Python file named 'word\_counter.py'.

3\. Run the program.

4\. Enter a paragraph when prompted.

5\. View the character, word, sentence, and space counts.



###### **Concepts Used**

\- Variables

\- User input and output

\- `if-else` statements

\- `for` loop

\- String methods like 'split()' and 'count()'
